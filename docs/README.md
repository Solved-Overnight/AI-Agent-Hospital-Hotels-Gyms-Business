# Dentist AI Agent --- Project Documentation

This folder contains the five baseline project documents prepared before
Stage 5.

``` text
backend/
└── docs/
    ├── 01-PRD.md
    ├── 02-technical-architecture.md
    ├── 03-security-document.md
    ├── 04-security-access-document.md
    └── 05-feature-ticket-list.md
```

## Documents

1.  **PRD** --- product scope, users, requirements, goals, and success
    criteria.
2.  **Technical Architecture Document** --- application architecture,
    database model, agent/RAG flow, transaction strategy, and testing
    architecture.
3.  **Security & Documentation Document** --- security principles, data
    handling, secrets, LLM/web risks, logging, clinical safety, and
    operational security.
4.  **Security & Access Document** --- roles, permissions,
    authentication, authorization, database/API access, audit events,
    and access review.
5.  **Feature Ticket List** --- implementation backlog and development
    sequence.

These documents reflect the current project direction, including the
daily-capacity appointment model rather than fixed
service-duration/time-slot scheduling.
